# 🌳 Parques Nacionais do Brasil - Mapa Interativo

Projeto de Extensão e Cultura UFABC. Uma rede social e mapa interativo para os Parques Nacionais do Brasil.

## 🚀 Como rodar o projeto localmente

1. Clone o repositório.
2. Abra o arquivo `index.html` no seu navegador (não precisa de servidor local para esta versão inicial).

## 🤝 Como colaborar (Fluxo de Trabalho)

1. Sempre crie uma branch para sua tarefa: `git checkout -b feature/nome-da-sua-tarefa`
2. Faça suas alterações (use IA para ajudar!).
3. Faça o commit: `git commit -m "feat: adiciona tela de login"`
4. Envie para o GitHub: `git push origin feature/nome-da-sua-tarefa`
5. Abra um Pull Request (PR) no GitHub para revisão.

## 📦 Tecnologias Atuais

- HTML5 / CSS3 (Tailwind CSS via CDN)
- JavaScript (Vanilla)
- Leaflet (Mapas)
